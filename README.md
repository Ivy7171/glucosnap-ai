# GlucoSnap AI

Hack for Health 2026

See it. Snap it. Know it.

GlucoSnap AI is a mobile-first diabetes self-management prototype.

Features:
- Snap a meal
- Capture glucose readings
- Scan restaurant menus
- Track glucose trends
- Demonstrate provider alerts

Built with HTML, CSS, JavaScript, and Gemini AI integration. Hosted using Netlify.
